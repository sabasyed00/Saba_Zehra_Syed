Infant Mortality Data Analysis

This project uses exploratory and geospatial analysis to examine patterns in infant mortality data and how they vary by location.

PythonExploratory analysisData visualizationPublic health
01 · Context

The problem

How does infant mortality vary across locations, and what patterns become visible when the data is mapped rather than viewed only as an overall figure?

02 · Method

The approach

The analysis uses exploratory data analysis and geographic visualisation, including choropleth maps and heatmaps, to examine regional differences in the dataset.
