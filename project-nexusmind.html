NexusMind — Clinical RAG System

How can a language model answer healthcare questions with useful context rather than relying only on what it learned during training? NexusMind explores retrieval-augmented generation (RAG) alongside instruction-tuned models in a clinical knowledge-support setting.

PythonLLMsRAGLlama-2GemmaFastAPIFAISS
01 · Context

The problem

Healthcare information needs context and careful handling. A fluent answer is not enough if a user cannot connect it to relevant source material. This MSc project investigates a retrieval-supported approach and compares it with instruction-tuned language-model behaviour in a healthcare-oriented use case.

02 · Method

The approach

Frame the task as a comparison between retrieval-augmented generation and instruction-tuned models. The RAG approach retrieves relevant passages from a knowledge collection (FAISS is listed in the project stack) and supplies that context to the language model. The project materials name Llama-2, Gemma, Python and FastAPI as technologies associated with the work.
